Политика конфиденциальности приложения NOX

Дата вступления в силу: 15 ноября 2026 г.

NOX — VPN-клиент для Android. Мы уважаем вашу приватность и собираем минимум данных, нужный для работы приложения.

Какие данные обрабатывает приложение

  • Ссылка подписки и настройки — хранятся только на вашем телефоне.
  • Идентификатор устройства, модель телефона и версия Android — отправляются только на сервер вашей подписки при загрузке списка серверов. Они нужны, чтобы сервис мог ограничить число устройств на одну подписку.
  • Список установленных приложений — читается только на телефоне, чтобы вы могли выбрать приложения, которые работают мимо VPN. Список никуда не отправляется.
  • Камера — используется только для сканирования QR-кода подписки, по вашему нажатию. Снимки не сохраняются и не отправляются.
  • Статистика трафика — объём переданных данных по дням, хранится только на телефоне.

Чего приложение не делает

  • Не записывает и не хранит историю посещённых сайтов и содержимое трафика.
  • Не показывает рекламу и не использует рекламные идентификаторы.
  • Не передаёт и не продаёт данные третьим лицам.
  • Не использует сервисы аналитики.

VPN-подключение

Приложение использует системную функцию Android VpnService, чтобы направить трафик устройства через зашифрованное соединение на сервер вашей подписки. Трафик не проходит через наши серверы, кроме случая, когда сервер подписки принадлежит нам.

Передача данных

Все соединения с сервером подписки идут по защищённому протоколу HTTPS.

Удаление данных

Все данные, которые хранит приложение, удаляются вместе с приложением или через «Настройки → Приложения → NOX → Очистить данные».

Дети

Приложение не предназначено для детей младше 13 лет и не собирает их данные намеренно.

Изменения

Если политика изменится, новая версия появится на этой странице с новой датой.
