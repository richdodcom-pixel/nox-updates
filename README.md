# SNOX — тестовые версии

Здесь выкладываются сборки приложения SNOX для Android.

## Как установить

1. Откройте страницу **[Releases](https://github.com/richdodcom-pixel/snox-updates/releases)** и скачайте файл `.apk` из последней версии.
2. Откройте скачанный файл на телефоне.
3. Если Android спросит — разрешите установку из этого источника (браузера или файлового менеджера).
4. Нажмите «Установить».

## Если вы ставили версии 0.1–0.4

Начиная с 0.4.2 приложение подписано новым постоянным ключом. Один раз **удалите старую версию SNOX**, затем установите новую. Дальше обновления будут ставиться поверх.

## Нашли ошибку?

Напишите в Телеграм-канал SNOX или создайте запись во вкладке **Issues**.
